# 02-analysis: 자산 제출 화면

입력은 01-references.md(레퍼런스 16개)와 prd.md §5·§6이다.

## 분석

### 레퍼런스에서 확인한 공통 패턴
1. 폼 구조: 업로드·등록 화면(수현이랑, 달다방, 럽맘)은 상단 내비게이션(뒤로/닫기와 화면 타이틀), 스크롤되는 입력 영역, 하단 고정 풀폭 CTA로 구성된다. 제목과 설명은 글자수 카운터(13/30, 15/200)와 함께 제공되고, 설명은 "(선택)"으로 필수 여부를 구분한다.
2. 비활성 CTA: 입력 전에는 하단 버튼이 회색 비활성이고 필수 입력이 차면 활성화된다(다글로 "받아쓰기", 조앤헤일리 "등록하기").
3. 임시저장 병행: 달다방은 하단에 "임시저장"(아웃라인)과 "저장"(채움) 두 버튼을 나란히 둔다. 제출 전 중간 상태를 허용하는 패턴이다.
4. 선택 입력은 칩, 드롭다운, 바텀시트로 분리: 수현이랑은 칩, 달다방은 드롭다운, 럽맘은 선택 행을 탭하면 바텀시트 목록이 뜬다. 필수 항목은 라벨에 "*"를 붙인다.
5. 단계 진행 표시: 럽맘은 진행바와 "2/3" 단계 표시를 쓴다. 항목이 많은 등록은 단계 분할로 부담을 낮춘다.
6. 등록 방식 선택 먼저: 차란은 첫 화면에서 안내 카드와 풀폭 "사진으로 등록하기" CTA, "또는" 구분선 아래 보조 입력(링크 가져오기)을 둔다. 등록 진입점은 빼기처럼 목록 우하단 플로팅 "+ 상품 등록" 버튼이 흔하다.
7. 공개 범위 컨트롤: 네이버블로그는 발행 옵션 시트에서 전체/이웃/서로이웃/비공개 4분할 세그먼트로 한 번에 비교·선택하게 하고, 아래에 "이 설정을 기본값으로 저장" 토글을 둔다. 배달의민족은 "비공개"를 체크박스+물음표 툴팁으로 처리한다. 쑥쑥찰칵, 셀레트립, 투두메이트는 "라벨 + 현재값 + 쉐브론" 행으로 현재 공개 범위를 항상 노출한다.
8. 검수 상태 안내: 조앤헤일리는 "검수 후 등록되며 진행 상황은 내 정보함에서 확인" 문구를 폼 상단에 둔다. 코오롱몰 릴레이 마켓은 "검수한 뒤 재판매"를 판매 진입 CTA 바로 위에 설명한다. 히로인스는 검수 통과 조건을 별도 안내 화면으로 보여준다.

### 레퍼런스로 해결되지 않는 부분 (PRD 기준으로 새로 설계)
- 기본값 "비공개" 공개 범위 컨트롤: 네이버블로그는 기본값이 "전체"이고, 셀레트립은 설정 화면에서 값만 "비공개"로 보여줄 뿐 업로드 폼 안의 선택 컨트롤이 아니다. 업로드 폼에서 기본 선택이 "비공개"이고 3옵션(비공개/멤버 공개/판매 신청)을 비교하는 컨트롤은 레퍼런스에 없다. PRD §6-5와 서비스 규칙(G-S)에 따라 새로 설계한다. 네이버블로그의 세그먼트 형태만 구조 참고로 쓴다.
- 금지 항목 안내 문구(개인정보, 고객정보, 회사기밀, 타인 저작물): 판매 신청 시 이 네 가지를 포함할 수 없다고 알리는 안내는 레퍼런스에서 찾지 못했다. PRD §6-7 판매 가능 기준 6, 7번과 G-S 규칙에 따라 새로 설계한다. 위치는 조앤헤일리 검수 안내처럼 폼 상단 또는 CTA 바로 위가 후보다.
- "판매 신청" 옵션의 권한 제한(판매 승인 회원만 선택 가능) 표현과 검수 상태 배지 6종 구성도 레퍼런스에 직접 대응이 없어 새로 설계한다.

## 반영할 부분

- 자산 제출 화면 상단 내비게이션: 뒤로가기 + 타이틀 "새 자산 등록" + 하단 고정 풀폭 CTA 구조 (§6-5)
- 제목·설명 입력에 글자수 카운터를 두고 설명은 "(선택)" 표기로 필수·선택 구분 (§6-5)
- 파일 첨부 영역을 폼 상단 가까이에 두고 첨부 전/후 상태를 구분 (§6-5)
- 공개 범위 선택 컨트롤: 비공개/멤버 공개/판매 신청 3옵션 세그먼트(네이버블로그 구조 참고), 기본 선택값 라벨 "비공개". 레퍼런스에 없어 PRD 기준으로 새로 설계 (§6-5)
- "판매 신청" 옵션은 판매 승인 회원만 선택 가능하도록 비활성 상태와 사유 문구를 함께 표시. 새로 설계 (§6-5)
- 판매 신청 선택 시 금지 항목 안내 문구(개인정보, 고객정보, 회사기밀, 타인 저작물 포함 불가)를 폼 안에 노출. 레퍼런스에 없어 PRD 기준으로 새로 설계 (§6-7)
- 판매 신청 선택 시 "검수 상태" 표시 영역과 "검수 후 승인됨까지 진행되며 진행 상황은 내 자산에서 확인" 안내 문구 (조앤헤일리 참고) (§6-5)
- 검수 상태 배지: 임시저장, 검수 대기, 수정 요청, 승인됨, 반려만 사용 (판매 중, 판매 중지는 Phase 2라 제외) (§6-5)
- 하단 CTA를 "임시저장"(아웃라인)과 "제출"(채움) 2버튼으로 구성하고 필수 입력 전에는 제출 비활성 (달다방, 다글로 참고) (§6-5)
- 내 자산 목록의 우하단 플로팅 "+ 새 자산" 진입 버튼 (빼기 참고) (§5)
- 제출 완료된 미션 제출물에서 "내 자산으로 전환" 진입점 (§6-4)
- 제출 직후 상태 변경이 알림으로 이어짐을 안내하는 문구 "상태가 바뀌면 알려드려요" (§6-8)
